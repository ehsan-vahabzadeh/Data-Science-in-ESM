# Weather forecast correction

The terms below describe the weather forecasting and evaluation concepts used in this project.

## Language

**Forecast initialization time**:
The time associated with the atmospheric state from which a forecast starts.

**Forecast lead time**:
The time between forecast initialization and the time for which a forecast is valid.

**Valid time**:
The time at which a forecast or reference weather value applies.

**Reference**:
A weather dataset used to assess a forecast; in our first experiment this is ERA5 reanalysis.
