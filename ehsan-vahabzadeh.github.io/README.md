# Ehsan Vahabzadeh — personal website

A lightweight academic portfolio focused on selected projects and publications.
The site uses plain HTML and CSS and does not require a build step.

## Preview locally

From this directory, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a public GitHub repository named `ehsan-vahabzadeh.github.io`.
2. Copy the contents of this directory into that repository.
3. Push to the `main` branch.
4. In **Settings → Pages**, choose **Deploy from a branch**, then select `main`
   and `/ (root)`.

The website will be available at <https://ehsan-vahabzadeh.github.io>.
